## 复验方式

使用 JDK 17、Android SDK 36、Gradle Wrapper 8.13，测试设备为 Android 14 Google APIs x86_64 模拟器。DJI 依赖只支持 ARM64；x86 Android 模拟器可验证本地业务，受保护的 DJI 原生库和 ARM64 Vosk 模型不会在转译层加载，语音不可用时保留文字指令。本机 SDK 为 `C:\Android_studio`，中文用户目录的 Gradle 测试进程通过 ASCII 缓存路径访问，避免参数文件编码错误。

```powershell
$env:JAVA_HOME = 'C:\Users\冯梓鹏\.jdks\temurin-17.0.19'
$env:ANDROID_HOME = 'C:\Android_studio'
$env:GRADLE_USER_HOME = 'C:\codex-runtime\gradle-cache'
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:connectedDebugAndroidTest --console=plain
```

依赖已缓存时可添加 `--offline`。工程保留既有依赖版本并配置可用镜像，无需临时初始化脚本。设备测试需先启动可用的 Android 模拟器或连接 Android 设备。

测试报告位于 `app/build/test-results/testDebugUnitTest/` 和 `app/build/outputs/androidTest-results/connected/`。安装包位于 `app/build/outputs/apk/debug/app-debug.apk`。

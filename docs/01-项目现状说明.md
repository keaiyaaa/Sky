## 1. 项目背景和目标

**天枢巡检（SkyPivotInspection）** 是一款面向电力/设施巡检场景的 Android 无人机地面站应用，基于**大疆 MSDK V5 5.18.0** 接入大疆无人机。目标用户在手机/平板上完成：规划巡检航线 → 执行巡检飞行 → 查看巡检任务与 AI 分析结果 → 导出巡检报告，并辅以语音 + 大语言模型（DeepSeek）的智能指挥能力。

产品名"天枢"来自仓库内应用名（Manifest `android:label="天枢巡检"`）与 `PreferenceManager` 的存储名 `tianshu_prefs`；工程名 SkyPivotInspection 来自 `settings.gradle.kts`。

项目由**三个历史子项目 + 一个主壳骨架**合并而成（依据：`app/build.gradle.kts` 内多处"来自 DJI-FLY-xxx"注释、`SkyPivotApplication.kt:14-17` 的自述）：

| 来源 | 合并后包 | 定位 |
|---|---|---|
| 主壳骨架 | 根包 + `ui/` + `drone/` | 首页导航、设置页、全局 DJI SDK 管理器 |
| DJI-FLY-aerial | `aerial/` | 航拍 + 离线语音识别 + LLM 意图识别 |
| DJI-FLY-kami | `kami/` | 航线规划 + WPML/KMZ 导出 + 任务上传 |
| DJI-FLY-asuka912 | `asuka/` | 巡检任务中心 + 本地数据库 + PDF 报告 |

## 2. 软件运行平台与技术栈

- **平台**：Android 7.0（API 24）及以上，目标/编译 SDK 36，仅横屏，仅 arm64-v8a（DJI MSDK 限制）。
- **技术栈**：Kotlin 2.0.21 + ViewBinding（无 Compose）、协程、Room 2.6.1、原生 SQLiteOpenHelper、MapLibre 10.3.5、OkHttp/Gson、Vosk 离线语音、Glide、系统 PdfDocument。
- **构建**：Gradle 8.13 + AGP 8.12.0，JDK 17。**基线构建已验证通过**（`assembleDebug` 成功，APK 约 181MB；单元测试 6/6 通过）。

## 6. 前后端 / 数据库 / SDK 现状小结

- **前端**：上述 Android 应用（唯一交付物形态）。
- **后端**：无代码、无接口、无部署。设计文档规划了 14 张 MySQL 表（用户、无人机、航线、航点、巡检任务/记录/明细、AI 记录、工单、会员套餐、Token 流水、订单、用户设置、系统配置）——**这是规划蓝图，不是已部署系统**。
- **本地数据库**：三套并存互不相通——asuka 的 Room `inspection_db`（2 表，演示数据）、kami 的 SQLite `route_planning.db`（2 表，航线）、SharedPreferences `tianshu_prefs`（10 个设置 key）。**均不与 14 表设计对应**。
- **无人机 SDK**：真实接通的能力 = SDK 注册/连接、模拟器、避障开关、拍照/录像、设备信息查询；断链的能力 = 任务上传与起飞（注册状态检查脱节）、真机遥测；完全缺失的能力 = 起降返航摇杆指令、返航高度/失控行为/低电量下发、图传解码。

## 8. 已知缺陷与限制（摘选，完整见审计报告 §11）

1. 航线任务真机链路必然失败（注册状态机脱节）——最核心的断链。
2. 巡检不拍照：航点的拍照动作不写入 WPML。
3. 任务中心点击第二组日期任务后详情页空白（索引错位 Bug）。
4. 飞控/图传设置"同步成功"假象（8 个桩恒失败仍提示成功）。
5. 语音在线意图识别必失败（Key 占位符 + 围栏解析代码损坏）。
6. 实时数据不来自飞机（遥测 TODO）；模拟电量永不低于 20%。
7. 起飞/降落/返航/摇杆指令不存在；无起飞前检查；禁飞区仅硬编码北京三区且仅添加时检查。
8. Mock 演示数据首次运行固化进数据库并被多模块共享。
9. 主线程数据库/文件 I/O（拖拽航点每帧写库）有卡顿风险。
10. 无签名配置、无 README、无 CI、App 图标是系统占位图。

| 风险 | 说明 |

## 10. 后续最优先的工作（建议顺序）

1. **修 Bug 与清障**（低风险高收益）：任务中心索引错位、LLM 围栏解析、语音竞态、相机模式失败仍拍摄、主线程 I/O、死代码隔离。
2. **消除"假象"**：设置同步如实反馈成功/失败；Mock 数据加演示模式开关。
3. **打通真机航线链路**：统一 SDK 注册状态（D-01），接入真机遥测，导出拍照动作——让"规划→上传→起飞→巡拍"成为真实闭环。
4. **补飞行安全链路**：返航高度/失控行为/低电量真正下发，起飞前检查。
5. **再谈后端**：按 14 表设计先落地最小后端（登录 + 任务同步），避免在 Mock 上继续堆积功能。

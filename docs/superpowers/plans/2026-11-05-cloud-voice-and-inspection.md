# 联网语音与云端巡检实施计划

## 已确认的产品边界

- 航拍语音采用按住录音、松开发送；ASR 与意图分析都必须联网调用云端，不保留 Vosk 或关键词离线执行回退。
- 意图服务先提取中文关键词候选，再由 DeepSeek 结合原始表达判断；飞控意图仍经过既有参数校验和用户确认，真实飞行动作不在本任务范围。
- 巡检画面不在手机运行模型。Android 仅接收 DJI 视频帧，做限频、重复帧及画质筛选、缩放和 JPEG 编码，再上传 Docker 后端调用 DeepSeek 视觉模型复核。
- 后端通过环境变量读取 DeepSeek、百炼 API key 和百炼 Workspace API 地址。音频、图片只在请求期间内存处理，不落业务数据库。
- 不部署、不调用真实云 API、不提交、不推送。用户在聊天中提交的百炼 key 不写入仓库或工具日志；因其已暴露在聊天中，完成后提醒轮换。

## 实施步骤

1. 为后端关键词分类、模型响应解析、输入限制及图像筛帧逻辑建立针对性测试。
2. 在根仓库新增 Spring Boot 无状态 API：健康检查、在线语音识别+意图分析、文本意图分析、巡检图片分析。服务端使用环境变量配置凭据；外部错误响应不透出上游密钥或响应正文。
3. 新增 Dockerfile、Compose 和部署说明；默认只将 API 绑定到本机回环地址，并要求为外部访问配置 HTTPS 与客户端访问控制。
4. Android 端移除 Vosk 识别调用及全部离线意图回退；按住录音并在松开后把 WAV 上传到后端。语音或模型调用失败时清晰报错，不执行本地命令。
5. Android 端监听 DJI RGBA 帧，按低频率和画质/重复度规则筛选后压缩上传；将静态虚构检测结果替换为服务端真实返回的“复核中/疑似异常/未发现明显异常/服务不可用”状态。
6. 运行后端测试、Android 相关测试与 Debug 构建；审查 diff、工作树和所有配置样例，确认没有 key 或不相关文件改动。

## 需要配置或现场确认的条件

- 百炼 ASR 使用 Qwen3-ASR-Flash 的 Workspace 专属兼容 API 地址，因此部署时需填写区域与 Workspace ID。
- Android 需要部署后的 HTTPS 后端地址；生产部署还需有效 TLS 证书和可供手机访问的网络入口。
- DJI 解码回调与真实机型/云台相机索引需要真机验证；没有已连接 DJI 视频源时，检测应提示不可用，不得把演示视频当作真实实时图传。
- DeepSeek 视觉模型可给出自然语言可疑项和理由，但不提供已校准的缺陷置信度或像素级检测框；UI 不显示准确率或虚构置信度。

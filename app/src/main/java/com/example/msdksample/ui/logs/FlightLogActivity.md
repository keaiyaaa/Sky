# 飞行日志页面

2026-11-05增量：当前实现以项目根目录 `docs/F21开发与验收.md` 及 `docs/backend/f21.openapi.yaml` 为准。页面已分当前身份本机、未归属历史、账户三个范围，支持分页、分类、来源、日期和字面量关键词；本机及运行日志均按日志归属过滤。旧记录不自动归入当前账号。上报为明确选择的单条业务事件，演示、运行视图及未归属事件不上传。以下段落保留先前本地阶段说明。

## 作用与入口

首页侧边菜单“飞行日志”打开 `FlightLogActivity`。页面显示本机连接、设置同步和已经实际发生的本地模拟巡检事件，不把演示记录改标为真实设备执行。

```kotlin
startActivity(Intent(this, FlightLogActivity::class.java))
```

无必填 Intent 参数、props、emits 或公开页面方法。通过关键词输入、来源下拉选择和“查询／刷新”更新最近 200 条日志。

## 数据来源与联动

- 连接及设置事件仍从既有 `LocalDataStore.logs()` 查询。
- 本地巡检事件从 `MissionRunRepository.logs()` 直接读取正式状态事件表，不复制到另一份数据库。
- 本地巡检在来源筛选中归入“本地演示”，任务编号为稳定的执行记录 ID，详情包含航线 ID。
- 关键词按字面量匹配，百分号和下划线不作为通配符。
- 两种来源查询在 IO 线程执行，按事件时间稳定倒序合并，用户更换筛选时取消旧请求。

## 最小业务接入

F11 创建运行并提交状态事件后，飞行日志页面在重新进入或刷新时即可查询，无需额外调用另一数据库的写入接口。状态和日志因此始终引用同一份正式事件。数据库读取失败显示失败提示，不补充虚构结果。
